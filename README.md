Implements semi-autonomous driving for Crazy Car (Crazy Car Controller Arduino V2.0)

How it works:
  1) You collect training data, for any path that you may wish to be imitated by the Crazy Car.
  2) You train an imitation-learning model using the data you collected.
  3) You port the model to the car.
  4) Once you press the start button on the car, it drives autonomously.
